1. Identidad Visual y Principios de Laboratorio

Espresso Lab descarta toda plantilla genérica de blog de consumo o cafetería. La interfaz adopta el lenguaje visual de manuales de servicio instrumental, software de adquisición de datos y bancos de ensayo metrológicos. Cada elemento tipográfico y cromático cumple ratios estrictos de contraste WCAG AAA.

3. Componente de Scroll Obligatorio (.tabla-scroll)

Toda matriz de parámetros mecánicos o hidráulicos se confina dentro de un contenedor dedicado con desbordamiento horizontal controlado para garantizar la accesibilidad completa en pantallas de 320 px a 390 px sin deformar la retícula editorial:

.tabla-scroll {
  width: 100%;
  overflow-x: auto;
  -webkit-overflow-scrolling: touch;
  margin: var(--space-md) 0;
}
